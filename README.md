#Smart Umbrella for Bikes and Cycles using IoT
IoT-based smart umbrella system for bikes and cycles with automatic rain and sunlight protection.

## 📌 Project Overview

An IoT-based automated umbrella system designed for bikes and
cycles to provide protection from rain and sunlight.

The system uses environmental sensors to automatically control
the umbrella mechanism and provide hands-free operation.

## 🚀 Features

- Automatic rain detection
- Automatic umbrella opening and closing
- Temperature monitoring
- UV/sunlight protection
- Wind monitoring
- Servo motor-based mechanism
- IoT monitoring using Blynk
- Real-time sensor response
- Adjustable mounting system

## 🛠️ Technologies Used

- ESP32 / NodeMCU
- Arduino IDE
- Blynk IoT
- Servo Motor
- Rain Sensor
- Temperature Sensor
- UV Sensor
- Wind Sensor

## 🔧 Hardware Components

- ESP32 / NodeMCU

- Umbrella Mechanism

## ⚙️ Working

1. Sensors continuously monitor environmental conditions.
2. The controller receives sensor readings.
3. When rain is detected, the system activates the motor.
4. The umbrella automatically opens.
5. When conditions become suitable, the umbrella can be closed.
6. Sensor information can be monitored through the Blynk application.
